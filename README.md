# lab-test-2026-conference-half

Warmup project for lab test 3 of *High-level programming languages 2*: the **conference** sample sheet, starting state
**half** (the model classes with their fields: you add the annotations and the rest).

* The sheet: [test-3-conference.md](https://github.com/INBPA0315L/notes-2026/blob/main/warmup/sheets/test-3-conference.md)
* The tutorial of the model and the repository: [model-conference.md](https://github.com/INBPA0315L/notes-2026/blob/main/warmup/model-conference.md)
* The tutorials of the queries: [warmup](https://github.com/INBPA0315L/notes-2026/blob/main/warmup/README.md)
* The complete solution: [solutions/conference](https://github.com/INBPA0315L/notes-2026/blob/main/warmup/solutions/conference)

Open the project in IntelliJ IDEA with a JDK 25 environment and the *Lombok* plugin enabled. Do not modify the
`base` package and the `data.json`.
